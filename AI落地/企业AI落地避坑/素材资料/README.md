## 二、五颗最值钱的钻石（按书稿用途）

### 💎 1. 第三方视角的独立评估（文件 03）——第八章案例的"外部证据"

这是**唯一一份由外部技术服务商写的、对某大型药企 AI 大赛的独立分析报告**（25 页）。它和内部汇报的差别，正是本书最需要的东西：

- 内部汇报说"我们办得很成功"，第三方报告说"**参赛队伍集中在生产/质量/EHS 部门，说明场景选对了**"，并且**独立统计了部门参与分布**。
- 它同时点出了**问题**：项目难度、可行性、推广风险。
- **为什么值钱**：这本书的第八章要讲"真实案例复盘"，而读者对厂商写的东西天然打折。用一份**厂商的独立评估**来佐证，可信度立刻上一个台阶。

**建议用法**：第八章案例一（大赛作为"群众路线式 AI 推广"的样本），或者第一章坑四（"推动难还是推动易"）。

### 💎 2. 一张真实的一手任务台账（文件 08）——第二章场景全景的底座

第 14 页那张表是**整个素材库信息密度最高的一页**。它把「任务 / 主要内容 / 计划开始 / 计划完成 / 完成情况」五列摊开，等于把"AI 项目到底怎么立项"的过程完整记录了一遍：

| 看到的事实 | 对书稿的价值 |
|---|---|
| 数字员工（企业微信版）2024-10 启动、2025-2 完成，状态"**已完成各项技术准备，具备上线要求**" | 真实场景 + 真实状态（非 PPT） |
| 自研数字员工平台（本地知识库+云端大模型）状态"**技术可行性评估阶段**" | 完美对照：同一件事，评估 vs 上线，差在哪 |
| 采购预测模型"**已完成招标**" | 有采购动作 = 有预算 = 可算账 |
| 集团统一知识库"搭建至少4个开源知识管理平台**还在选型阶段**" | 选型难的真实证据 |
| DeepSeek 云端测试环境"**已在寻找云计算测试资源**" | 基础设施的真实卡点 |

**建议用法**：第二章的场景卡片模板，直接用这张表当反例——**"上线"和"具备上线要求"是两个状态**。这一点别的 AI 落地书不会讲。

### 💎 3. AI 工程化组织的完整样本（文件 15）——第五章的稀缺素材

一份 V2.0 的**分中心章程**：名称与性质、宗旨使命定位、职责分工、区域协同枢纽、人才互用机制。

**为什么稀缺**：市面上的 AI 落地书几乎都在讲"要成立 AI 团队"，但**没有一份给得出组织章程长什么样**——职责怎么切、汇报线怎么画、和母公司研究院怎么分工、三方（研究院/分中心/另一集团）怎么互用人才。

**建议用法**：第五章「落地五步法」中的"组织与授权"一节。读者最缺的就是这个——**章程模板本身就是附录素材**。

### 💎 4. 预算明细（文件 11、12）——第六章算账的唯一硬数据

文件 11 第 8 页有**按项目分项的预算说明**：数字员工算力与软件、RPA 外部采购与实施、采购价格预测模型（软件+实施+数据购买）等，各项都有量级。

**注意**：金额已做模糊化处理（原值已不可反查）。**第六章如果要用真实数字，必须由老周重新提供一次**，或者用"约XX万"的模糊量级表述。

**建议用法**：第六章成本结构五项的第一份真实样本 + 第八章"这个项目算过账吗"的正面案例。

### 💎 5. 一整套激励机制（文件 05、06、07）——第五章推广机制的实证

三份文件构成一条完整的激励设计链：

- **05 实施方案**：评选范围、评选标准与流程、激励形式与兑现、风险控制与动态管理（**有"风险控制与动态管理"整章，说明设计者想过翻车**）
- **06 激励计划**：评选维度权重——**成果达成度 60% / 创新性 20% / 协作贡献 20%**
- **07 考核激励方案**：里程碑节点激励（"开心花"）、延期调整机制（"地雷花"触发后的抵消规则）、重大质量事故取消当年激励

**为什么值钱**：这解决了一个全书反复出现却没人写清的问题——**AI 项目怎么做成"业务部门自己要干"而不是"IT 部门推不动"**。答案是：把激励从"项目奖"改成"**过程节点奖**"，并给延期留了可申请的调整阈值。

> 这套机制的**"延期可申请调整阈值"**这一条，是很多企业都做错的——考核方案一僵化，业务部门就会为了不触发惩罚而拒绝立项。**这是可以写成金句的素材。**

## 五、脱敏规则说明

| 类别 | 处理方式 |
|---|---|
| 母公司及关联企业名 | 统一替换为「某大型药企」「该药企」「某头部医药集团」「该集团」 |
| 关联医药企业名 | 统一替换为「某医药集团」 |
| 分中心名称 | 替换为「某集团研究院AI工程分中心」 |
| 内部部门名 | 数字化中心类统一为「数字化中心」；品牌名统一为「某文化品牌」 |
| 同事姓名（134 人） | 替换为「成员01」～「成员134」，编号稳定可反查（映射表单独存放） |
| 地理信息 | 「云南省昆明市」→「某省某市」，「云南省」→「某省」 |
| 金额 | 精确值 → 模糊量级（约400万 / 约50万…） |
| 外部厂商 | 影刀→「某RPA厂商」，国双→「某第三方技术服务商」，中邮证券→「某证券研究机构」 |
| 长数字/手机/邮箱 | 一律打码 |
