## 二、定位论证（决定全书骨架）

### 两本书的区隔
| 维度 | 《数据治理实战》 | 《企业AI落地实战》 |
|------|------------------|-------------------|
| 核心命题 | 数据治理 = 治责任，不是治数据 | AI落地 = 治决策，不是治技术 |
| 视角 | 自下而上：先把数据治干净 | 自上而下：先找到值钱的场景 |
| 读者收获 | 怎么建体系、怎么定责权 | 怎么选场景、怎么不踩坑、怎么算账 |
| 关键差异 | 讲"平台和制度" | 讲"业务价值和投入产出" |

### 核心钩子（可作宣传语）
> **数据治理是 AI 的地基，但 90% 的企业顺序搞反了——先上 AI，再补数据，最后发现是数据问题。**

### 为什么你的视角值钱
市面上 AI 落地书 90% 是工具测评和提示词技巧（写给个人用户），真正写给"企业 IT 负责人"的极少。你有 20 年制药信息化 + 数据治理体系 + 央企组织政治三样叠加，是稀缺组合。
**差异化一句话**：别人教你怎么把 AI 用起来，我告诉你**为什么你的 AI 用不起来，以及先做什么**。

## 三、今日资料包要点

### 要点1：AI 落地的四大基石（可直接复用，零改写成本）
> 来源：`电子书/数据治理实战：从二级分类到落地执行.md` 引言《AI时代，数据治理的第三次浪潮》

```
当AI落地企业时，真正有价值的是四样东西：
  ① 数据    ← 一切的基础
  ② 流程   ← 最终也是数据
  ③ 知识   ← 最终也是数据
  ④ 规则   ← 最终也是数据
```

配套金句（**本册引言可直接用**）：
- 当AI落地企业时，数据、流程、知识、规则最终都是数据的形式呈现——数据治理成了重中之重。
- 本体论的根基是数据，没有数据治理，本体论就是空中楼阁。
- AI转型不是买一套AI系统，数据治理才是AI转型的入场券。

**用法**：本册引言的核心论证——"为什么 AI 落地绕不开数据治理"，用这四条打底，读者立刻理解。

### 要点2：AI 转型要回答的三个问题（引言的第二段论证）
> 来源：同上

```
AI落地企业，需要回答三个问题：
问题1：数据是什么？
问题2：关联关系是什么？
问题3：规则在哪里？
结论：如果没有数据治理，连数据都说不清，AI转型就是空谈。
```

### 要点3：阻力不是技术，是政治 —— 本册核心洞察的种子
> 来源：电子书《数据治理的真正阻力：不是技术，是政治》核心章

```
数据治理表面上是技术问题（标准不统一、质量差、系统不互通、平台不好用）
但这些往往是借口，真正的原因藏得更深：
  └── 责权的博弈 / 权力的让渡 / 工作方式的改变
```

**四大阻力来源**（D5 改写成"AI 抵触四层"时直接用）：
1. 部门不愿公开数据（数据透明=业绩透明=压力透明）
2. 数据管理部门不愿放权（担心职能被架空）
3. 工作方式的改变（Excel 台账习惯 vs 系统化）
4. 责权博弈与再分配

**本册转译**：AI 项目失败往往也是政治问题——因为 AI 触碰的是"谁的工作方式被改变""谁的蛋糕被动"，不是模型准不准。

### 要点4：主数据为什么阻力不大（AI 场景选型的判断依据）
> 来源：电子书核心章

```
主数据治理阻力不大，因为主数据是"别人的数据"：
  各部门用别人的数据，用好了大家都受益
  组织架构主数据 → 各部门都要用
  客户主数据 → 销售、市场、客服都要用
```

**本册转译**：这是场景选择的一个隐藏判据——**凡是"本部门自己用自己数据"的场景，AI 落地阻力一定大；凡是"用别人的数据补自己短板"的场景，阻力小**。

### 要点5（今日新增）：新第二章的"起点论"——本册第三章的杀手锏
> 来源：电子书第二章《主数据治理与数据治理：到底谁先谁后》（今日新写，10 月 26 日）

这一章今天刚写完，**核心观点可以直接搬进本册第三章「数据准备」**：

```
主数据治理不是数据治理的起点，是数据治理摸清家底之后的第一个突破口。
你不可能在没看过全量数据之前，宣布哪些数据是主数据。
治理范围不是规划出来的，是问题暴露出来的。
主数据清单，不是拍出来的，是"盘出来 + 指标筛出来"的。
```

**AI 语境的转译**（本册第三章的立论）：
- 很多企业先上 AI（选场景/定方案），再补数据 —— 跟"先做主数据治理"是同一个错误
- AI 的场景清单也不是拍出来的，是"业务痛点 + 数据摸底"盘出来的
- 加上本书自己的观点：**RAG 失败九成不是模型问题，是检索问题；检索质量的根是文档没治理干净**

### 要点6（今日新增）：成熟度分档法可直接改造成 AI 落地的起点分档
> 来源：电子书第二章（同上）

```
L0 无体系      → 先建体系（制度→组织→摸家底）
L1 有制度无全景 → 先入湖 + 资产盘点（让数据见面）
L2 有全景有标准 → 可从主数据切入，但清单需指标复核
L3 治理常态化   → 不存在起点问题，只有排期问题
```

**本册转译**：AI 落地的起点也按数据成熟度分档——L0/L1 先治数据别谈 AI，L2 可试点，L3 才谈规模化。
