# 企业数据管理制度（模板参考）

> 来源：昆药集团数据管理制度（已脱敏）
> 整理：米悦
> 日期：2026-10-15

## 第一章 总则

### 目的与依据

为规范企业数据管理活动，确保数据真实性、准确性、完整性和可追溯性，防范数据风险，释放数据价值，根据《药品管理法》《数据安全法》《个人信息保护法》《药品生产质量管理规范》（GMP）等法律法规及行业标准，结合企业实际情况，制定本制度。

### 适用范围

本制度适用于集团总部及各下属子公司的所有部门、员工，以及与集团数据管理活动相关的第三方合作方。

### 管理原则

1. **真实性原则**：严禁编造、篡改、伪造数据
2. **完整性原则**：确保数据全生命周期不丢失
3. **可追溯原则**：数据变更全程留痕
4. **安全性原则**：数据分级保护，权限最小化

## 第二章 数据分类分级

### 数据分类

| 类别 | 说明 |
|------|------|
| 客户数据 | 客户基本信息、联系方式、交易记录 |
| 产品数据 | 产品编码、规格、属性 |
| 供应商数据 | 供应商资质、准入信息 |
| 财务数据 | 财务核算相关数据 |
| HR数据 | 人员信息、组织架构 |

### 数据分级

| 级别 | 定义 | 保护要求 |
|------|------|---------|
| 核心数据 | 涉及商业秘密的数据 | 最高级别保护，严格审批 |
| 重要数据 | 涉及经营敏感的数据 | 限制共享范围 |
| 一般数据 | 内部公开数据 | 正常权限管理 |

## 第三章 管理组织与职责

### 数据治理委员会

- 主任：分管副总裁
- 成员：信息中心、业务部门负责人
- 职责：制定数据战略、审批重大制度、协调跨部门事项

### 信息中心（数据管理办公室）

- 负责数据管理制度制定和执行监督
- 负责主数据管理平台建设和运维
- 负责数据标准制定和发布

### 业务部门

- 负责本部门业务数据的录入、更新和维护
- 配合数据治理委员会的工作
- 执行数据质量改进措施

## 第四章 主数据管理

### 主数据标准

- 统一编码规则
- 统一属性标准
- 统一数据源入口

### 主数据生命周期

```
创建 → 审核 → 发布 → 分发 → 使用 → 变更 → 废弃
```

### 主数据分发机制

主数据由主数据管理平台统一管理，向下游系统分发，保证数据一致性。

## 第五章 数据质量管理

### 质量评估维度

- 准确性：数据与实际业务一致
- 完整性：必填字段不缺失
- 一致性：跨系统数据口径统一
- 时效性：数据更新及时
- 唯一性：无重复数据

### 质量改进流程

1. 数据质量检测
2. 问题分析根因
3. 制定改进方案
4. 执行改进措施
5. 验证改进效果

## 第六章 数据安全管理

### 权限管理

- 最小权限原则
- 角色-based access control
- 定期权限审计

### 数据备份

- 定期全量备份
- 实时增量备份
- 异地容灾

## 第七章 附则

本制度自发布之日起施行，由信息中心负责解释。
