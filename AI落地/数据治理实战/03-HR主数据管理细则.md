## 第一章 总则

### 目的

为规范集团HR主数据全生命周期管理，建立统一、规范、唯一的HR主数据体系，解决主数据多源、口径不一、系统割裂等问题，实现HR主数据跨业务系统、跨部门共享复用与数据一致性。

### 适用范围

集团总部及各下属子公司

### 管理原则

1. **唯一性原则**：主数据全局唯一，不得重复创建
2. **标准化原则**：按统一标准编码和属性填写
3. **共享性原则**：主数据全局共享，各系统调用统一数据源
4. **可追溯原则**：主数据变更全程记录

## 第二章 主数据分类

### 组织架构数据

| 类型 | 说明 | 示例 |
|------|------|------|
| 公司 | 集团下属法人单位 | 集团总部、子公司 |
| 部门 | 公司内设组织 | 销售部、研发部 |
| 岗位 | 部门内设岗位 | 销售经理、研发工程师 |

### 人员主数据

| 类型 | 说明 |
|------|------|
| 员工基本信息 | 工号、姓名、性别、出生日期 |
| 任职信息 | 所属公司、部门、岗位、入职日期 |
| 合同信息 | 合同类型、签订日期、到期日期 |

## 第三章 管理组织与职责

| 角色 | 职责 |
|------|------|
| 数据治理委员会 | 审批重大事项、协调跨部门问题 |
| 信息中心 | 平台建设、技术支持、标准发布 |
| 人力资源部 | HR主数据业务管理、数据维护 |
| 业务部门 | 本部门相关数据的填报和确认 |

## 第四章 主数据生命周期管理

### 创建

1. 业务部门发起主数据创建申请
2. 人力资源部审核
3. 信息中心复核
4. 主数据管理平台发布

### 变更

1. 业务部门发起变更申请
2. 原审核路径复核
3. 平台更新并通知下游系统

### 废弃

1. 业务部门发起废弃申请
2. 确认无下游系统使用
3. 标记废弃，不再分发

## 第五章 数据标准

### 编码规则

- 公司编码：6位数字
- 部门编码：8位数字（公司码+序号）
- 岗位编码：10位数字
- 员工编码：10位数字（入职年份+序号）

### 属性标准

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 编码 | 字符串 | 是 | 全局唯一 |
| 名称 | 字符串 | 是 | 标准全称 |
| 简称 | 字符串 | 否 | 日常使用 |
| 状态 | 枚举 | 是 | 正常/禁用 |
