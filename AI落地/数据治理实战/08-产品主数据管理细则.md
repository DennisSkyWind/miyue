## 第一章 总则

### 目的

为实现产品主数据的标准化和统一数据源管理，统一产品主数据的管理统计口径，明确产品数据标准化管理流程及相应环节职责分工。

### 适用范围

集团总部及各下属子公司

### 管理原则

产品主数据在主数据管理平台维护创建的信息，由主数据管理平台统一管理和分发，供相关下游消费系统调用查询产品主数据。

## 第二章 产品分类

### 产品类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 处方药 | 需处方才可购买 | RX开头编码 |
| OTC | 非处方药 | OTC开头编码 |
| 保健品 | 保健食品 | 健字号 |
| 医疗器械 | 医疗相关产品 | 器械字号 |

### 产品线分类

按治疗领域分类：消化系统、心脑血管、抗感染、精神类等

## 第三章 编码规则

### 产品编码结构

```
类型码(2位) + 类别码(2位) + 流水号(6位) = 10位编码
```

### 示例

| 产品类型 | 编码示例 |
|------|------|
| 处方药 | RX00010001 |
| OTC | OT00010001 |

## 第四章 主数据属性标准

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 产品编码 | 字符串 | 是 | 全局唯一 |
| 产品名称 | 字符串 | 是 | 标准名称 |
| 规格 | 字符串 | 是 | 如：0.5g×12片 |
| 单位 | 字符串 | 是 | 最小销售单位 |
| 生产厂家 | 字符串 | 是 | 生产企业 |
| 产品分类 | 枚举 | 是 | 见产品类型分类 |
| 医保目录 | 枚举 | 否 | 是否在医保目录 |

## 第五章 管理流程

### 创建流程

1. 业务部门发起产品主数据创建申请
2. 产品信息完整性审核
3. 药品注册证等资质审核
4. 主数据管理平台创建并发布

### 变更流程

产品主数据变更需经原审核路径复核后方可更新。
