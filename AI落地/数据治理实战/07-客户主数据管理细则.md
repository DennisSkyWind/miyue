## 第一章 总则

### 目的

为实现客户主数据的标准化和统一数据源管理，统一客户主数据的管理统计口径，明确客户数据标准化管理流程及相应环节职责分工。

### 适用范围

集团总部及各下属子公司

## 第二章 客户分类标准

### 客户类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 医院 | 医疗机构 | 公立医院、私立医院 |
| 连锁药店 | 药品零售连锁 | 大型连锁药房 |
| 商业公司 | 药品批发企业 | 医药商业公司 |
| 诊所 | 基层医疗机构 | 私立诊所、卫生室 |
| 个体药店 | 单体药店 | 单体药房 |

### 客户分级

| 级别 | 定义 | 服务要求 |
|------|------|---------|
| A级 | 核心客户 | 优先供货、专属客服 |
| B级 | 重要客户 | 优先处理 |
| C级 | 普通客户 | 标准服务 |

## 第三章 编码规则

### 客户编码结构

```
类型码(2位) + 区域码(4位) + 序号(4位) = 10位编码
```

### 示例

| 客户类型 | 编码示例 |
|------|------|
| 医院 | HY00010001 |
| 连锁药店 | LS00010001 |
| 商业公司 | SY00010001 |

## 第四章 主数据属性标准

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 客户编码 | 字符串 | 是 | 全局唯一 |
| 客户名称 | 字符串 | 是 | 标准全称 |
| 客户类型 | 枚举 | 是 | 见客户类型分类 |
| 地区 | 字符串 | 是 | 所在地区 |
| 地址 | 字符串 | 是 | 详细地址 |
| 联系人 | 字符串 | 是 | 主要联系人 |
| 电话 | 字符串 | 是 | 联系电话 |
| 等级 | 枚举 | 是 | A/B/C级 |

## 第五章 管理流程

### 创建流程

1. 业务部门发起客户主数据创建申请
2. 客户信息完整性审核
3. 客户资质审核（营业执照等）
4. 主数据管理平台创建并发布

### 变更流程

1. 业务部门发起变更申请
2. 变更内容审核
3. 平台更新并通知下游

### 废弃流程

1. 确认无下游系统使用
2. 标记废弃
3. 保留历史记录
